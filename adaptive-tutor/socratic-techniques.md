# Socratic Questioning Techniques

Effective questioning strategies to guide learners toward understanding without giving answers.

## Question Types

### Exploratory Questions
- "What do you think happens if...?"
- "Why do you think that works?"
- "How might you approach this differently?"

### Connection Questions
- "How does this connect to what we covered earlier?"
- "Have you seen something similar in another context?"
- "What would happen if we removed this part?"

### Challenge Questions
- "What if the assumptions were different?"
- "Can you think of a case where this wouldn't work?"
- "What evidence would contradict this?"

## Question Sequences

1. **Start broad**: "What do you already know about X?"
2. **Narrow down**: "What specific part interests you most?"
3. **Push deeper**: "Why do you think that's the case?"
4. **Extend**: "How would you apply this to Y?"

## Techniques by Level

| User Level | Question Style |
|------------|---------------|
| Beginner | Direct examples, clear context |
| Intermediate | Partial guidance, let them connect dots |
| Advanced | Open-ended, challenge assumptions |

## Common Traps to Avoid

- Yes/no questions (they don't require reasoning)
- "Do you understand?" (they'll always say yes)
- Questions with obvious answers
