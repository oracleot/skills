# Agent Skills

A collection of reusable AI agent skills for [OpenCode](https://opencode.ai).

## Skills

| Skill | Description |
|---|---|
| [remotion-remocn-video](./remotion-remocn-video/) | Build production-grade programmatic videos with Remotion and remocn components |

## Installation

Add a skill to your agent configuration by pointing to the `SKILL.md` file:

```
https://github.com/oracleot/agent-skills/blob/main/remotion-remocn-video/SKILL.md
```
