# Telescope live-demo example

This tracked example demonstrates the canonical `present-demo` Electron shell with a local, credential-free product fixture. Its story is **signal → investigation → decision**.

Run it in three terminals:

```sh
npm install
npm run fixture
npm run dev
```

Then run `npm run smoke` while the fixture and Electron app are running. The template-level browser controls let you navigate among `/`, `/retention`, and `/brief`; the Presenter Notes window controls the same runbook state as the audience window.

The `Telescope` theme is intentionally fictional. It demonstrates a project-specific tone without using or implying a real product's brand assets.
